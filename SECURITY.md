# Security Policy

Never deploy `lab/vulnerable_agent.py`; it exists only to demonstrate a bearer-token anti-pattern. The reference broker is also not a production authorization server.

Use only synthetic or explicitly authorized systems. Never commit credentials, private keys, bearer tokens, customer identities or production authorization receipts.

Report vulnerabilities using GitHub private vulnerability reporting when available. Include the affected version, synthetic reproduction, impact and suggested mitigation. Avoid public exploit details that create immediate harm.
